# Changelog

Every release of TCG Master Set, derived automatically from [Conventional Commits](https://www.conventionalcommits.org/) on each merge to `main`.

While the version is below `1.0.0`, the bump is shifted down one level: a breaking change is a minor, a feature is a patch.
